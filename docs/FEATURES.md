# Kuma AI Web App Features

## Core Experience
- Fast chat mode for instant answers
- Thinking mode for deeper reasoning
- Agent mode for goal-based multi-step execution
- Multi-turn conversations with editable history
- Clean web and mobile UI with markdown support

## Agentic Capabilities
- Autonomous task loop: plan, execute, verify, refine
- Tool-using agents that can browse, read, write, and summarize
- Parallel sub-tasks for faster completion
- Checkpointed runs so users can pause and resume tasks
- One-click rerun with improved constraints

## Deep Search and Research
- Live web search with source citations
- Deep research mode that scans many pages before synthesis
- Evidence-first answers with quoted sources
- Contradiction detection across sources
- Report generation: brief, standard, or long-form

## Long Context Intelligence
- Long context conversations for large documents and threads
- Context caching for faster follow-up responses
- Grounded recall from earlier chat and project memory
- Automatic chunking and retrieval for large knowledge files

## Multimodal Understanding
- Image understanding for screenshots, charts, and diagrams
- OCR extraction from photos and scanned docs
- Audio-to-text input and voice prompt support
- Mixed-input prompts (text + image + file) in one turn

## Workspace and Projects
- Project spaces for teams, clients, or personal workflows
- Shared project memory and instructions
- Upload docs, PDFs, CSVs, slides, and code files
- Smart indexing with retrieval-aware chat
- Scoped permissions per project and connector

## Artifacts and Output Creation
- Create webpages, docs, tables, and slide drafts from prompts
- Generate structured outputs: JSON, CSV, markdown, and reports
- Editable artifact canvas with version history
- Export to link, PDF, and source files

## Automation and Integrations
- Native connectors for drive, docs, chat, tasks, and code platforms
- Trigger actions from chat (create ticket, send summary, update doc)
- Background jobs for long-running agent tasks
- Webhook and API support for product workflows

## Personalization and Memory
- Persistent user memory with full controls
- Memory scopes: global, project, and session
- Style presets for tone, format, and depth
- Transparent memory viewer with edit and delete options

## Safety, Privacy, and Trust
- Source-linked outputs for auditability
- Permission gates before sensitive actions
- Incognito sessions with no persistent memory
- Admin controls, role-based access, and audit logs

## Performance and Reliability
- Low-latency streaming responses
- Smart model routing by task complexity
- Graceful fallback when tools or connectors fail
- Session recovery after network interruptions
